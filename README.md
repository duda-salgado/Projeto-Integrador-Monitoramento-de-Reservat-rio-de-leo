# Projeto Integrador — Monitoramento de Reservatório

**PROJETO INTEGRADOR | 4º SEMESTRE | Análise e Desenvolvimento de Sistemas — 2026**

## 📌 Sobre o Projeto

Este projeto tem como objetivo desenvolver um sistema de monitoramento de reservatório, integrando a coleta de dados por meio de um microcontrolador e a visualização das informações em um dashboard web.

O sistema também conta com telas específicas para diferentes tipos de usuários, permitindo a separação das funcionalidades de acordo com o perfil de acesso.

## 📂 Organização dos Arquivos

O repositório contém os arquivos necessários para o desenvolvimento do projeto, incluindo os códigos do microcontrolador e as interfaces web.

### Versão Antiga

A pasta **Versão Antiga** contém os códigos de versões anteriores do projeto, mantidos para consulta e histórico de desenvolvimento.

Nessa pasta, estão armazenadas versões antigas de diferentes partes do sistema, incluindo:

- **Layout do dashboard:** versões anteriores da interface de monitoramento.
- **Código da IDE do Arduino:** versões anteriores do código responsável pela coleta de dados do sistema.

Esses arquivos permitem acompanhar a evolução do projeto, consultar implementações anteriores e comparar as alterações realizadas ao longo do desenvolvimento.

## 🖥️ Funcionalidades Atuais

Atualmente, o projeto conta com as seguintes telas e funcionalidades:

- **Tela de login:** interface de autenticação para acesso ao sistema.
- **Dashboard do operador:** interface destinada ao operador, com recursos de acompanhamento do sistema.
- **Dashboard do gestor:** interface destinada ao gestor, com visualização das informações pertinentes ao seu perfil.

## 🔄 Histórico de Versões

REV. 1 — Revisão do escopo e das funcionalidades do sistema

Alterações realizadas:

Código da IDE do Arduino: foi removida a coleta dos dados de temperatura e pressão, pois essas informações eram simuladas e não representavam medições reais.

Layout do dashboard: foram removidos os elementos de visualização dos dados de temperatura e pressão, mantendo a interface alinhada às informações efetivamente utilizadas pelo sistema.

Escopo do projeto: foi retirada a proposta de implementação de Inteligência Artificial (IA) preditiva, reduzindo o escopo do sistema e direcionando o desenvolvimento às funcionalidades essenciais de monitoramento do reservatório.

Tela de login: foi desenvolvida uma tela para permitir o acesso ao sistema.

Dashboard do operador: foi criada uma interface específica para o perfil de operador.

Dashboard do gestor: foi criada uma interface específica para o perfil de gestor.

Objetivo da revisão: adequar o escopo e as funcionalidades do sistema às necessidades atuais do projeto, eliminar dados simulados, retirar a proposta de IA preditiva e implementar interfaces específicas para os diferentes perfis de usuário.
