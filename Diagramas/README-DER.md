O Diagrama Entidade-Relacionamento (DER) apresenta a estrutura proposta para o banco de dados do sistema de monitoramento de óleo, identificando as entidades, seus atributos e os relacionamentos existentes entre elas.
A modelagem contempla o armazenamento das informações dos usuários, tanques, dispositivos, sensores, medições, configurações de limites, alertas e resultados da análise de anomalias. Cada entidade possui uma chave primária para sua identificação, enquanto as chaves estrangeiras estabelecem as relações entre os registros.
A estrutura proposta busca garantir a organização, integridade e rastreabilidade dos dados coletados, permitindo consultas históricas, acompanhamento dos níveis dos tanques e armazenamento dos resultados produzidos pelo sistema de análise inteligente.
